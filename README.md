## Writing (`/writing`)

Posts are markdown files in `src/content/writing/`. Drop in a file and it's live — the filename is the URL.
See `src/content/writing/writing-template.md` (a `draft`, so it only shows in `npm run dev`) for every block type:
frontmatter, `> [!NOTE|INFO|TIP|WARNING|KEY|QUOTE] title` panels, ` ```ts title="file.ts" ` code blocks with copy,
tables, footnotes, `<details>`, and `## September 3rd, 2026` journal date markers. Images go in `public/writing/`.
